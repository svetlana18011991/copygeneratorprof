ЕГЭ ПРОФИЛЬНЫЙ — ПРОБНОЕ ОБНОВЛЕНИЕ ССЫЛОК (21 ДЕНЬ)
=====================================================
Только для copygeneratorprof. Основной генератор не менять!
Архив содержит только обновление к уже работающей короткой версии, а не весь банк.

УСТАНОВКА ОДИН РАЗ
1. Распакуйте все содержимое ZIP непосредственно в локальную папку
   Документы → GitHub → copygeneratorprof, с заменой файлов.
   Обязательно скопируйте и папку .github, и папку ege_versions, и tests.
   index.html и link_trial.js должны лежать в корне. app_core.js не заменяется.
2. В GitHub Desktop убедитесь, что выбран copygeneratorprof. Проверьте наличие
   .github/workflows/ege-pages.yml в Changes. Сделайте Commit to main и Push origin.
3. На странице https://github.com/svetlana18011991/copygeneratorprof/settings/pages
   в Build and deployment → Source выберите GitHub Actions вместо Deploy from a branch.
   Это нужно один раз: теперь сайт публикует наш собственный процесс сборки.
4. Перейдите во вкладку Actions (https://github.com/svetlana18011991/copygeneratorprof/actions).
   Выберите Publish EGE with 21-day versions. Если после смены Source он еще не шел,
   нажмите Run workflow → main → Run workflow (зеленая кнопка).
   Дождитесь зеленой галочки. Если возникнет ошибка, не меняйте рабочий репозиторий;
   откройте ошибочный шаг и пришлите скриншот. Старую рабочую версию не удаляйте.
   Если Actions отключены, сначала разрешите стандартные GitHub Actions в Settings → Actions.
5. Откройте пробный сайт в новой вкладке, Ctrl+F5. Создайте новый вариант, нажмите
   Ссылка для ученика (тест). Должна появиться короткая ссылка с #student=3. и дата окончания.
   Откройте ее через «Проверить в новой вкладке». Испытайте ввод ответа и проверку.
   Старые ссылки #student=2. и исходные JSON-ссылки тоже должны открываться через
   прежний адрес в течение 21 дня от первой успешной публикации нового механизма.

КАК РАБОТАЕТ
- Новый URL хранит срок (21 день с точностью до минуты), идентификатор опубликованного
  коммита, состав варианта и общую контрольную сумму. При генерации новых ссылок
  проверяется актуальная версия: если вкладка устарела, нужно обновить ее.
- Ни каждый вариант, ни ответы ученика не записываются в репозиторий. Скачивание HTML
  остается прежним, без нового ограничения срока.
- При каждом push и по ежедневному расписанию GitHub Actions заново собирает сайт.
  Измененные старые версии берутся из истории Git. Одинаковые архивные файлы хранятся
  один раз по хешу. Старые версии, переставшие быть активными, оставляются 23 дня
  (21 день плюс резерв на публикацию/кэш); затем исключаются из публикации.
  Старые данные не вычищаются из истории Git. Если расписание GitHub отключит из-за
  отсутствия активности, очистка снова произойдет при очередной успешной публикации.
- Сохраненные в самом репозитории рисунки и банк сохраняются по версии. Внешние картинки,
  подключенные по интернет-адресам, не архивируются этим способом. Если внешний ресурс
  изменится, гарантий его прежнего состояния нет. Собственные загруженные фоны/стикеры
  по-прежнему доступны только в скачиваемом HTML, не в компактной ссылке.
- Проверка срока в браузере не является серверной защитой от намеренного обхода.
  Если дата/время устройства существенно неверны, ссылка может быть отклонена.
- Первоначальная сборка на тестовой копии занимает примерно 603 МБ (включая архивный
  набор). При проверке добавление изменения к одному заданию и рисунку увеличило объем
  менее чем на 1 МБ. Безопасный предел сборки 950 МБ: если лимит превышен, публикация
  завершается ошибкой, не удаляя молча необходимые старые версии.
- В прошлых ссылках без даты невозможно узнать исходную дату создания. Для них общий
  переходный срок 21 день с момента первой публикации. Старые ссылки, созданные на еще
  более раннем отличающемся банке, могут отклониться при проверке контрольной суммы.
- Очистка сайта не требует отдельных серверов, карт или действий учителя. Не переписывайте
  историю Git (force push), пока есть действующие ссылки: архивы берутся из нее.

ПРОВЕРКИ
Node-тесты: ручные и случайные варианты, 15 заданий, формат старых JSON-ссылок,
контрольная сумма, срок, устаревшая вкладка, маршрутизация на нужную версию.
Полная локальная сборка: старый банк и старый рисунок после их изменения сохранены,
неизмененные файлы общие; после 25 дней от замены старая версия удалена из публикации.
Браузерный тест заблокирован средой запуска (ERR_BLOCKED_BY_ADMINISTRATOR), а выполнение
Actions на GitHub еще не проверено: обязательно проверьте на пробном сайте.
Срок действия не заменяет резервные копии и не гарантирует непрерывность работы хостинга.
