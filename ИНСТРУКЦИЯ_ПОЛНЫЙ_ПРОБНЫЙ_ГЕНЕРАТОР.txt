ПОЛНЫЙ ПРОБНЫЙ ГЕНЕРАТОР «ЕГЭ ПРОФИЛЬНЫЙ» — ССЫЛКИ ДЛЯ УЧЕНИКОВ

Этот архив содержит ВЕСЬ проект из предоставленного исходного архива
«generator11prof-main (5).zip» и добавленную тестовую возможность
отправлять интерактивные варианты по ссылке без интернет-хранилища.

Рабочий сайт prof.sistema-math.ru и действующий GitHub-репозиторий
svetlana18011991/generator11prof НЕ МЕНЯЛИСЬ.

СОСТАВ
- Все файлы и банки заданий исходного проекта: JS, HTML, изображения,
  оформление, игры и прочие материалы.
- index.html и app_core.js заменены тестовыми версиями.
- Новый файл link_trial.js: создание и открытие ученических ссылок.
- Тесты tests/link-trial.test.cjs.
- Файл CNAME намеренно УДАЛЁН: он относится к действующему домену!
- Исходная возможность скачать HTML сохраняется.
- В тестовом app_core.js также присутствует ранее подготовленное
  исправление повторных загрузок картинок при сохранении HTML.

КАК СОЗДАТЬ ОТДЕЛЬНЫЙ ПРОБНЫЙ САЙТ
1) Создайте отдельный ПУСТОЙ репозиторий GitHub, например:
   generator11prof-test. НЕ загружайте файлы в generator11prof!
2) Скачайте и РАСПАКУЙТЕ этот ZIP.
3) Загрузите ВСЕ распакованные файлы и папки в КОРЕНЬ нового
   репозитория. index.html должен быть в корне, а не внутри дополнительной
   папки. Удобнее загрузить проект через GitHub Desktop: скопируйте
   распакованные файлы в папку клонированного тестового репозитория,
   выполните Commit и Push. Большой ZIP напрямую как одну веб-страницу
   загрузить нельзя.
4) Откройте в тестовом репозитории Settings → Pages.
   Выберите Deploy from a branch, затем main и /(root), нажмите Save.
5) Дождитесь опубликования сайта. Его адрес будет примерно:
   https://svetlana18011991.github.io/generator11prof-test/
   (имя пути зависит от точного имени тестового репозитория).
6) Откройте ПРОБНЫЙ адрес, создайте интерактивный вариант,
   нажмите «🔗 Ссылка для ученика (тест)» → «Копировать ссылку».
7) Проверьте эту ссылку в режиме инкогнито и на планшете/телефоне;
   откройте работу, введите ответы и проверьте результат.
8) Проверьте, что прежняя кнопка «Скачать HTML» продолжает работать.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Ссылки работают после публикации сайта в интернете. Для запуска
  страницы двойным щелчком по index.html они не предназначены.
- В ссылке сохраняется состав заданий и настройки; ученику требуется
  интернет, чтобы открыть страницу и загрузить банк задач.
- Если изменится исходное задание в банке, старая ссылка может перестать
  работать: генератор не должен незаметно открывать другую задачу.
- Собственные картинки-фоны с устройства и пользовательские стикеры
  не передаются по ссылке; для них оставлено скачивание HTML.
- Некоторые изображения из внешних источников могут требовать интернет
  и не гарантированы офлайн. Результаты видит ученик, учителю они не уходят.
- Это пробный релиз. Тесты кода пройдены, но открытие всех видов заданий
  на всех реальных планшетах и браузерах заранее не гарантировано.
